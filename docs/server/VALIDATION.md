# Проверка патча сотрудников

Выполнено: 25 исполняемых проверок модели EmployeeAccess; проверка синтаксиса
всех Dart-файлов lib через tree-sitter; отдельный Dart analyze модели доступа
(ошибок не обнаружено). Эти проверки не подтверждают сборку всего приложения.

Добавлены Flutter-тесты test/employee_access_test.dart. Они не запускались.
Полная Flutter-проверка и APK не выполнены: автоматическая проверка безопасности
отклонила запуск Flutter из-за попытки обращения к endpoint метаданных среды.
Обход блокировки не выполнялся. Kotlin-код также не компилировался в этой среде.

На ветке andcode-test перед установкой:

```sh
flutter pub get
flutter analyze --no-fatal-warnings --no-fatal-infos
flutter test test/employee_access_test.dart
flutter build apk --release
```

На реальном телефоне проверить открытие/закрытие клавиатуры в авансовом отчёте,
остатке газа, ТО, сотрудниках и направлениях; поворот/возврат из фона; длинные
формы и открытие поля у нижнего края. Плавность анимации на устройстве пока
не измерялась.

С сервером выполнить сценарии из EMPLOYEES_API.md на двух телефонах: единственный
владелец, изменение прав при открытом разделе, отзыв сеанса, блокировка,
отсутствие сети, повтор отправки, конфликт версий, фоновый GPS и закрытие смены.
Удалённая блокировка без связи применяется после получения политики либо
истечения сохранённого допуска; мгновенная офлайн-блокировка не гарантируется.

Данные накладных передаются как записи. Локальные пути к изображениям не делают
фотографии доступными на другом телефоне: для файлов требуется серверное
хранилище и отдельный API загрузки. Этот патч не переносит бинарные фотографии.
